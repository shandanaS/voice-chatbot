# 🎙️ Siri-Like Voice Chatbot (Google Colab)

A voice assistant built entirely in Google Colab using:
- 🧠 DialoGPT (Microsoft) — conversational AI
- 🎤 SpeechRecognition — voice-to-text
- 🔊 gTTS — text-to-speech
- 🌐 Browser microphone via JavaScript

## How to Run
1. Open the notebook in Google Colab
2. Run each step in order
3. Allow microphone access when prompted

## Features
- Browser mic recording
- Speech recognition (Google API)
- AI-generated responses
- Voice playback output
